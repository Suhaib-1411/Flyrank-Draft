The Problem

Tracking new vulnerabilities across public databases is manual and time-consuming. I needed an automated way to query CVE endpoints and extract structured threat intelligence without manual web navigation.

The Build

I engineered an autonomous Python agent that connects directly to the live MITRE CVE API. It retrieves raw JSON vulnerability definitions, parses technical flaw mechanisms, and formats clean Markdown intelligence briefs locally.

import requests

def fetch_cve_data(cve_id):
    url = f"https://cveawg.mitre.org/api/cve/{cve_id}"
    response = requests.get(url, timeout=10)
    return response.json() if response.status_code == 200 else None
